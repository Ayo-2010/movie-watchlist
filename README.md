# Movie Watchlist

A small film tracker with add, search, filter and watched states.

## Features

- Add a film with a title, year and genre
- Mark films as watched or move them back to the watchlist
- Remove films
- Filter by all, to watch or watched
- Search by title
- Counts for each list, saved in local storage
- Three sample films on first load

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
